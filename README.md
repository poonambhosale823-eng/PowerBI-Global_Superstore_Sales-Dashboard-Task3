# Global Superstore | Sales Intelligence Dashboard (Task 3)

Interactive Power BI dashboard analyzing Global Superstore sales, profit, and regional performance (2011-2014).

## 📌 Project Overview
This project involves cleaning the Global Superstore dataset and building an interactive Power BI dashboard to turn raw order data into clear, decision-ready insights.

## 📂 Repository Contents
- `Dashboard.pbix` – Power BI dashboard file
- `cleaned_dataset.csv` – Dataset after cleaning and preprocessing
- `screenshots/` – Images of the dashboard

## 🧹 Data Cleaning Steps
- Removed duplicate records
- Handled missing/null values
- Corrected data types (dates, numbers, text)
- Standardized column names and formatting

## 📊 Dashboard Features
- **KPI cards:** Total Sales, Total Profit, Total Orders, Profit Margin
- **Monthly Sales Trend:** line chart showing sales growth from 2011 to 2014
- **Regional Pulse:** bar chart comparing sales across regions
- **Profit vs Sales by Sub-Category:** bubble chart colored by category
- **Top 5 Products by Sales:** bar chart of best-selling products
- **Slicers:** Order Date, Region, Category, and Segment for interactive filtering
- **Key Insights panel:** summary of main findings

## 🔍 Key Insights
1. **Central region leads:** it contributes $2.82M (22.3% of total sales), the highest of all regions.
2. **Technology is the most profitable category:** $0.66M profit with a 14.0% margin.
3. **Strong sales growth:** sales rose steadily year over year from 2011 to 2014.
4. **Top products:** Phones ($1.71M) and Copiers ($1.51M) lead in sales.
